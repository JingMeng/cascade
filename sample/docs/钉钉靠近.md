# 钉钉风菜单实现记录

## 结论

`fb2716a` 新增的是 `showWithOffsets()`，解决的是弹窗显示偏移，不是 padding。

当前钉钉风样式通过在 sample 中启用自定义 `CascadePopupMenu.Styler` 实现，Cascade 的默认外观和原有调用方式不变。

## 库层扩展

为保留向后兼容，没有修改原有方法语义，只新增了以下可选能力：

- `CascadePopupMenu.setPopupElevation()`：设置弹窗阴影高度。
- `CascadePopupMenu.setPopupMargins()`：设置弹窗四周透明留白，供阴影完整显示。
- `MenuItemViewHolder.setItemMargins()`：设置菜单项行外边距，影响背景和 ripple。
- `MenuItemViewHolder.setItemHeight()`：设置菜单项固定行高。

原 `show()` 仍使用默认的 `4dp / 0dp / 4dp / 4dp` 边距，旧调用行为不变。

## 最终样式

- 主菜单移除“消息免打扰”，保留三项：邀请成员、搜索、更多。
- “更多”子菜单：房间详情、权限设置、退出房间。
- 弹窗宽度：`160dp`，适配四字菜单项，不再按五字文案保留多余宽度。
- 阴影：`8dp`，弹窗四周预留 `8dp` 透明空间。
- 卡片圆角：`10dp`。
- 菜单项高度：`44dp`。
- 菜单项左右外边距：`8dp`。
- 列表上下留白：`4dp`。
- 内容左右留白：`16dp / 14dp`。
- 图标尺寸：`20dp`，图标与文字间距：`12dp`。
- 文字：`14sp`，近黑色。
- 分组分隔线：隐藏。
